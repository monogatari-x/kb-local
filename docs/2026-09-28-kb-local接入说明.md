# kb-local 知识库:项目说明 & 接入指引

## 一句话

把我们平时写在项目里的文档(设计文档、排查记录、任务书、操作手册)自动汇到一个公司统一的知识库里,谁用 AI 助手(Claude Code / Codex)都能一句话搜到,并且**每篇文档都署名**——知识找得到、不流失、有归属。

## 它解决什么问题

1. **"这个功能当时是谁做的、怎么做的?"——直接问 AI 就有答案。** 不用翻群聊、翻目录、问了一圈才发现人已离职。
2. **文档写了没人看得到的问题。** 很多人认真写了文档,但藏在各自项目的文件夹里,别人根本不知道存在。进了知识库,所有人都能搜到。
3. **知识是公司的,不是个人电脑里的。** 所有文档每天自动归档到公司服务器,按人分目录。人员交接时,把目录整份拷给接手人;评价产出时,按人能看到沉淀了多少。

## 实际效果(真实例子)

向 AI 提问"专家评审回避规则怎么恢复",回答里直接给出:

> 来源:[pingtao.cao] yaf/docs/2026-08-03-专家评审回避规则功能归档.md 第 16 行
> "在素养提升活动的专家评审环节,防止专家评审与自己有利益关系的作品,共 4 档回避规则……"

带作者、文件、行号。目前库里已有 **260 多篇文档、2.2 万条可检索内容**,覆盖 yaf、数据中台、禅道等 20 来个项目。

## 大家怎么参与(重点)

### 第一步:知道"写在哪里会被收录"

**每个项目根目录下的 `docs/` 文件夹**,里面的 md 文档都会被自动收录。例如:

```
D:\Glow\Projects\yaf\docs\2026-09-15-xxx排查记录.md   ← 会被收录
D:\Glow\Projects\yaf\src\代码文件                      ← 不会
```

写作建议(不强求,但建议保持团队现有惯例):文件名用 `日期-主题.md`
(如 `2026-09-28-登录超时排查.md`),内容开头写一句背景。

**只要文档放进项目的 docs/ 目录,后续收录、更新、归档全自动,不需要任何手动操作。**

### 第二步:想用 AI 搜索的同事(一分钟接入)

在 Claude Code 或 Codex 的配置里加一条(找曹平涛拿现成的配置和口令):

- Claude Code:一条 MCP 服务配置,指向公司服务器
- Codex:同样一条

加完之后,AI 助手就多了"搜公司知识库"的能力,零安装、不占自己电脑资源。

### 第三步:想让**自己项目的文档**进库的同事(一次性配置,约 10 分钟)

因为项目在你自己电脑上,需要在你电脑上配一个"自动上传"任务(写好文档后每小时
自动把变更推到公司服务器)。管理员把 kb-local 仓库发给你,在仓库目录执行一条命令
(`scripts\setup_contributor.ps1`,约 10 分钟,无需管理员权限),之后完全无感。

## 数据放哪了、谁能看

- 所有文档归档在公司服务器(192.168.0.10)`/data/RAG/bak/` 目录,**按人分文件夹**
- 搜索服务需要口令(token)才能用,不对匿名开放;口令由曹平涛统一发放
- 每篇文档的检索结果都带作者名,谁的产出一目了然

## 已实测验证(2026-09-29)

新同事从零接入的完整流程已在 Windows 环境实际跑通:模拟新用户完成
安装、服务器开通、文档归档、AI 工具搜索,**端到端约 20 分钟**,
最终在其自己的会话里搜到了署名文档。过程中发现的 5 类环境问题
(安装权限、服务器账号、配置遗漏等)全部固化进了一键脚本,
后续接入按第 1~3 步执行即可,不再需要人工排查。

## 适合什么场景用

- **开发/运维**:查某功能的设计与历史、排查记录、上线步骤——AI 直接引用原文
- **交接**:接手人接住的是"文档+可搜索的知识库",而不是一堆没有头绪的代码
- **新人**:不用挨个问人,先问知识库
- **主管/评价**:按作者统计知识沉淀,作为工作评价的参考之一

## 遇到问题怎么办(常见几条)

| 现象 | 一句话处理 |
|---|---|
| AI 工具里连不上官方服务(403) | 缺公司中转站配置,找管理员要"AI 环境包"跑一条命令 |
| 装完脚本后备份显示 0 个文档 | 监控目录没配上,把实际项目根路径告诉管理员,补一条命令 |
| 文档备份了但搜不到 | 等一个同步周期(最长 1 小时);仍不行找管理员看服务状态 |
| 电脑上运行命令提示"禁止运行脚本" | 常见的 Windows 安全设置,管理员已统一处理;个别情况按提示执行一条设置命令 |

## 边界说明(如实)

- 搜索依赖内网能连到公司服务器;在家/外网时不可用(文档本身不受影响)
- 新写的文档从保存到可被搜到,最长 1 小时(自动同步周期)
- 目前收录范围:各项目 docs/ 目录下的文档;代码本身不入库
