# kb-local 知识库:是什么 & 怎么接入

## 一句话

把每个人项目里写的文档(设计文档、排查记录、任务书等)自动收进一个可搜索的知识库,AI 助手(Claude Code / Codex)写代码、查问题时能直接搜到引用,**不用再问"这个功能当时是谁怎么做的"**。

## 实际效果(真实示例)

向 AI 提问"专家评审回避规则怎么恢复",直接返回:

```
[pingtao.cao] yaf/docs/2026-08-03-专家评审回避规则功能归档.md:16-17
  在素养提升活动的专家评审环节,防止专家评审与自己有利益关系的作品,
  共 4 档回避规则,可多选启用……
```

带作者、带文件、带行号。目前库内已有 **260+ 篇文档、2.2 万条可检索片段**,覆盖 yaf、数据中台、禅道等 20 来个项目。

## 接入步骤(每人每台机器,约 10 分钟)

1. **装**:克隆 kb-local 仓库 → `uv sync` 装依赖 → 下载 AI 模型(约 5 分钟)→ Docker 启动向量库
2. **配身份**:在 `~/.kb/config.yaml` 写一行 `author: 自己的禅道账号`
3. **开监控**:执行 `kb watch add <项目根目录> --include "*/docs/*"`,以后 docs 下的文档**新增/修改自动入库**,无需任何手动操作
4. **接 AI**:Claude Code / Codex 里加一条配置,搜索工具即可用

> Windows 和 Mac 都支持(Mac 会自动用芯片加速)。

## 知识自动归档(公司资产,不是个人资产)

- 每天自动备份到公司服务器 **192.168.0.10 的公用目录 `/data/RAG/bak/`**
- **按人分目录**(如 `/data/RAG/bak/pingtao.cao/`),每篇文档带作者标识
- **工作交接**:把接手人的目录整棵拷给他,文档沉淀不随人走而流失
- **工作评价**:可按人统计知识产出(多少文档、什么内容)
- 不配身份不让备份——知识产出必须有主

## 管理与维护

- 各机器独立运行、互不影响,无单点故障
- 服务器目录统一管理(公用 `rag` 组权限),新成员接入只需运维加一次权限
- 后续人多后,可在服务器起一个聚合检索入口,实现"搜全公司所有人的知识"
